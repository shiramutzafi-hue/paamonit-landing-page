# פעמונית – דף נחיתה

דף נחיתה סטטי (HTML + CSS + מעט JavaScript) לעסק **פעמונית** של ריטה וניסים סמדג'ה מאילת.
אין בקאנד ואין שלב בנייה. פותחים את `index.html` בדפדפן וזה עובד.

## מבנה התיקייה

```
index.html        התוכן והמבנה של הדף
css/styles.css    העיצוב (נייד ומחשב)
js/main.js        הודעת טופס
favicon.svg       האייקון בלשונית הדפדפן
images/           תמונות
video/            סרטונים
```

## איך לפתוח ולצפות

- **ב-VS Code:** לפתוח את התיקייה (`File > Open Folder`). לצפייה עם רענון אוטומטי אפשר להתקין את התוסף **Live Server** וללחוץ `Go Live`.
- **בלי VS Code:** לחיצה כפולה על `index.html`.

## מבנה הדף

1. באנר עליון: תמונה של ריטה וניסים, עם כותרת מימין
2. הסיפור שלנו (חלק א): טקסט מימין, סרטון משמאל
3. הסיפור שלנו (חלק ב): תמונה מימין, טקסט משמאל
4. כל פריט יחיד במינו: טקסט מימין, תמונה משמאל
5. היצירות: שלושה כרטיסי קטגוריות
6. צור קשר: וואטסאפ, טלפון, רשתות חברתיות וטופס

## תמונות שחסרות

כל מקום לתמונה מסומן בדף במסגרת מקווקוות עם שם הקובץ. ב-`index.html` יש מעל כל אחד הערה עם הקוד להחלפה.

| קובץ | איפה בדף |
|---|---|
| `images/story.jpg` | הסיפור שלנו, חלק ב |
| ✅ `video/videochimes.mp4` | הסיפור שלנו, חלק א (סרטון, הוכנס) |
| `images/handmade.jpg` | כל פריט יחיד במינו |
| ~~`images/cat-chimes.jpg`~~ ✅ `images/cat-chimes.webp` | כרטיס פעמוני רוח (הוכנס) |
| ✅ `images/cat-lamps.webp` | כרטיס גופי תאורה (הוכנס) |
| ✅ `images/cat-jewelry.jpg` | כרטיס תכשיטים (הוכנס) |

טיפים: תמונות ברוחב של עד כ-1600 פיקסלים, דחוסות (JPG או WebP). סרטון קצר (עד כחצי דקה) ודחוס.

## צבעים

כל הצבעים מוגדרים בראש `css/styles.css` תחת `:root`. כשיהיו צבעי המותג הסופיים, מחליפים רק שם.

## הפעלת הטופס (בהמשך)

הטופס מוכן ל-**Netlify Forms**. עד שהוא מחובר, לחיצה על "שליחה" מציגה הודעה ולא שולחת.

1. להעלות את האתר ל-Netlify.
2. ב-Netlify: `Site configuration > Forms > Form notifications` ולהוסיף את המייל של העסק.
3. ב-`index.html` לשנות בטופס `data-ready="false"` ל-`data-ready="true"`.
